# Scripts PHP5 commentés

➡️ Cours associé : **[Introduction au langage PHP5 par l'exemple](https://stahe.github.io/php5-juillet-2011/)**

---

## Présentation

Ce document propose une **collection de scripts PHP5** couvrant différents domaines d'utilisation du langage. Il ne s'agit pas d'un cours complet mais plutôt d'un **recueil d'exemples pratiques** destinés à illustrer certaines fonctionnalités de PHP5 et à servir de base d'expérimentation pour les développeurs.

Les scripts présentés sont :

- commentés directement dans le code ;
- accompagnés de **leurs résultats d'exécution en console** ;
- parfois complétés par des **explications supplémentaires** permettant de mieux comprendre leur fonctionnement.

L'objectif du document est de proposer une **approche pratique du langage PHP5**, fondée sur l'étude et l'analyse de scripts.

---

## Public visé

Ce document est destiné à des développeurs ayant **déjà utilisé un langage de script**, par exemple :

- Perl  
- Python  
- VBScript  

Il suppose donc une **certaine familiarité avec les concepts de programmation scriptée**.

Les lecteurs n'ayant pas cette expérience préalable devraient plutôt commencer par un **cours complet sur PHP** avant d'utiliser ce recueil d'exemples.

---

## Méthode de lecture

Le document nécessite une **lecture active** :

1. Lire le code du script.
2. Examiner les commentaires intégrés.
3. Étudier les résultats d'exécution fournis.

C'est la combinaison de ces trois éléments qui permet de comprendre pleinement chaque exemple.
